APIPASS API Marketplace provides a platform that aggregates and resells access to various AI models at significantly reduced prices, offering developers a single integration point to leverage multiple large language and multimodal models. It features a unified API, transparent pricing, and tools for managing API keys, usage, and billing, targeting startups and enterprises seeking cost‑effective AI capabilities.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for APIPASS API Marketplace: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
